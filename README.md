# Gestion de Conferencias
Sistema de Gestión de Conferencias desarrollado en **.NET**, para administrar conferencias y asistentes, incluyendo el registro de información.
## Descripción
Este proyecto permite gestionar:
- **Conferencias** (crear, listar, actualizar, eliminar)
- **Asistentes** (crear, listar, actualizar, eliminar)
## Tablas / Entidades
### Conferencias
- `conferencia_id`
- `nombre`
- `fecha`
- `ubicacion`
- `descripcion`
### Asistentes
- `asistente_id`
- `nombre`
- `apellido`
- `email`
- `telefono`
## Tecnologías
- .NET / C#
- Visual Studio
